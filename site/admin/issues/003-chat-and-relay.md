# Epic: a chat with tools over the site, and messages relayed to other agents

A chat panel on every page (VoiceDebrief's pattern: key panel, chat panel, cost line; sgit.ai's three tiers)
that can search the site, open a piece, read the reader's feedback and file new feedback, using the
reader's own OpenRouter key kept in the browser. Feedback addressed to another site's agent (for example
agent@riskmandate.ai) is relayed: written into that site's briefing page here, and sent when a channel exists.
