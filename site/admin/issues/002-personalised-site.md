# Epic: the site shaped by what the reader has done

The published site is the editor's view. The reader's view is that view minus what they have marked read,
plus their notes, with a history of every action they can undo. Two named views to start ("the editor's"
and "the editor of record's"), more audiences later. State lives in the browser now and in a vault later,
so the daily agent can read it and several devices can share it. A graph of the pieces (what cites what,
what follows what) is what the dynamic rendering and "read next" should be built on.
