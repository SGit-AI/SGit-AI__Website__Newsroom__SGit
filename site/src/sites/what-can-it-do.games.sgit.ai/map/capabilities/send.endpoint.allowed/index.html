Reach a permitted list of hosts

send.endpoint.allowed — send × network-endpoint at tenant reach (the organisation's accounts, repositories and services). Family: network. Effect: cannot be undone.

What narrows it

The setting: shorten the list; a host it does not need is a host it can reach

What it costs: minutes per host, and a failure the first time it needs one you removed
