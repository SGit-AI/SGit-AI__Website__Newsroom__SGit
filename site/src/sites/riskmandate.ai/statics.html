RiskMandate — The post images

The 'How long will you accept this risk?' series as static 4:5 artboards, ready to screenshot and post. Same scenarios as the interactive cards, one renderer apart.

Source: https://riskmandate.ai/statics.html↗

The same series, as post images.

Four 4:5 artboards per scenario — hook, escape, reveal, interval — laid out to stop a scroll. It's the interactive card's data through a second renderer, so the posts can never drift from the demo. Pick a scenario, switch to clean view, screenshot each frame.

Four frames, one scenario at a time.

Each frame is a fixed 600×750 artboard. Choose a scenario below; use Clean view to drop the page chrome so every frame captures edge-to-edge.

The four-beat arc, frame by frame.

The hook

A question with an obvious answer — the kind anyone would refuse on instinct.

The escape

The reflex out — "not relevant to me" — named and then quietly closed.

The reveal

You already did it the moment an agent ran. States your own grant, never an attacker's move.

The interval

The real question isn't whether — it's how long. Six windows, from revoke-now to an owned deferral.

Post the image. Then send the demo.

The static set is the top of the funnel; the interactive page is where the point lands. Both end at an owned, time-boxed acceptance with a record behind it.
