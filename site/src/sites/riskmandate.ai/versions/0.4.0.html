IFD version structure + v0.4 redesign

Reworked versioning into an Iterative Flow Development (IFD) layout and shipped a redesigned site as v0.4.0, selectable alongside v0.3.0.

  • IFD folder structure. Each meaningfully-different version is its own folder under v{major}/v{major}.{minor}/v{major}.{minor}.{patch}/ — currently v0/v0.3/v0.3.0/ and v0/v0.4/v0.4.0/. Source mirrors this under src/versions/.
  • Working version selector. The root is now a thin host that loads the selected version into an isolated frame, so any two versions can be switched between without their components colliding. The dropdown defaults to the latest and lets you drop back to a previous one.
  • Static version number removed from the bar — the selector shows the current version itself.
  • v0.4 redesign (the better messaging and layout from review): vendor-anchored category framing with a trust-layer stack; the "20 agents that matter / 80% noise" trifecta with a 3/3 · 2/3 · 0–1/3 breakdown; a Discovery → Remediation value ladder with hope-vs-enforce bars; an interactive risk-acceptance window picker; a richer capability certificate with scoped permit/deny; a stronger closing call to action; and a four-column footer.
  • Deliberately not carried over from the reviewed design: the ticker, the fourth "Enterprise+" pricing tier, and the "interactive" hero hint — all removed earlier on purpose.
