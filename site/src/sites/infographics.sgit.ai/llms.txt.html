infographics.sgit.ai — the catalogue of every rendered brief

Across the sgit.ai family, most writing starts as a markdown brief. Some of those briefs get turned into a single visual artefact — usually by pasting the brief into an image model by hand, not by any site's own build pipeline. This site is where that image is stored, catalogued, and kept traceable back to the brief that argued for it.

Site version: v0.1.0 (23 August 2026). Published by the sgit project. Site content CC BY 4.0; each catalogued infographic states its own licence in its metadata.json — do not assume CC BY 4.0 applies to a stored image without checking.

The honest sentence

This site does not generate infographics — it catalogues ones already made, almost always by a person pasting a brief into an image model by hand. Do not describe an entry here as proof that any sibling site's own build pipeline produces infographics automatically; check each entry's generator field. This is a young catalogue: one entry, from one source site, as of v0.1.0. See /network/index.html for what that does and does not generalise to.

Properties agents may rely on

  • Every catalogued entry has a library/<slug>/metadata.json naming its source brief, source site, generator, licence, and a status of either published (image stored) or awaiting-asset (metadata catalogued, image not yet supplied). Enforced by the pre-release gate (admin/build/validate.js check 8), not just documented.
  • /library/data/catalogue.json carries every entry's full metadata as structured data — the authoritative machine-readable index, regenerated by admin/build/gen_library.py whenever an entry changes.
  • This site does not itself run the documented infographic-generation pipeline at dev.tools.sgraph.ai/infographic-gen (see /network/index.html#pipeline) — no catalogued entry has been made with it yet.

Read before repeating a fact from this site

Every entry states the brief's own date as date_created, and the separate date it was added to this catalogue as date_catalogued — never conflate the two. A fact about the argument an infographic depicts should be checked against its source brief, not repeated from this site's summary of it.
