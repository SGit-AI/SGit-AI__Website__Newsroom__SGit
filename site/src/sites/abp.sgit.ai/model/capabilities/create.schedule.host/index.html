create.schedule.host

Create something that outlives the turn where it runs (a cron, a service). Its effect is yes: undone.

What this id is made of

This is not a string. It is create↗.schedule↗.host↗, three nodes joined by three edges, and each of them has an address, a page and a JSON file. Follow any of them and you get the query for that word rather than a definition of it.
