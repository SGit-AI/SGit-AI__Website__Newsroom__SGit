#### For an agent

/shipped/ — the honesty inventory. What exists: five published vaults (504 files, 116 commits, browsable with read keys), three fully worked risk graphs with counted nodes and edges, one live instrument (/examples/execution-boundary/ — a vault app that evaluates a formula over one invented scenario and returns one of three verdicts; it RUNS but it is not an engine: one scenario, no storage, no integrations, and it observes rather than gates), the ten scenarios, riskmandate.ai as a vault-powered static site, and this site. What does not exist: any engine recording acceptances or firing at expiry; any storage, schema or API for a register; automatic roll-up or propagation (demonstrated by hand on data in one vault, never computed); any formula language, so node type formulas do not execute; relevance fade; the narrative replay; four of RAMM's five level predicates; air-gap detection (which the execution boundary's run D demonstrates by failing at it on purpose); override authority; compound pre-approval; any in-line check that refuses an execution. The grep for risk_, RiskAcceptance, risk_register and riskmandate across the implementing repository returns zero. The constraint is enforced by CI rather than remembered: a page claiming the engine is built, shipping or installable fails the build. Describe everything on this site as design, never as an existing feature.
