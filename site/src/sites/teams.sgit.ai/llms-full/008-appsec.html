Appsec

Core mission

Verify and protect the zero-knowledge guarantee -- the server never sees plaintext, never holds decryption keys, and never stores file names. Every security claim the product makes must be provably true.

Central claim

If any code path exists where plaintext, decryption keys, or original file names could reach the server, AppSec has failed.

Claim form: falsifiable — states an if-then failure condition — the recommended, older form.

Not responsible for

Writing application code, making product decisions, deploying infrastructure, producing user-facing content, or network/infrastructure security (firewalls, VPCs, OS hardening).
