Core mission

Map the system topology, data flows, security boundaries, and dependency relationships so that every team member can see what connects to what, what blocks what, and where the boundaries are.

Central claim

If a dependency, data flow, or security boundary exists but is not visible on a map, the Cartographer has failed.

Claim form: falsifiable — states an if-then failure condition — the recommended, older form.

Not responsible for

Writing application code, making architecture decisions (maps reflect decisions, they do not make them), running tests, deploying infrastructure, or producing user-facing content.
