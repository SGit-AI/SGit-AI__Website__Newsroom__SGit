One table, five columns, and the free one first

The comparison table every pricing page has and this store does not: features down the left, five columns across — free, £10, £50, £500, £1,500 — and a cell for every one. New page, so it can be reviewed before it is wired in.

What we read in it

The table is not a pricing page. It is the explanation

“This will make a massive difference in the understanding of what you actually get.” The store today explains each level on its own page, which means nobody ever sees the four side by side. Every difference the memo lists — a vault or not, dual licence, the board version, the mapping to standards, support — is a difference, and a difference is only legible next to the thing it differs from.

The free column goes first, and it is the whole argument

“You actually start with the free because it’s the one that you download.” The templates being free has been treated on this site as an objection to answer. Putting the free column first turns it into the first row of the sales argument: here is what you can have for nothing, here is what each step buys, and the licence column alone explains the first step.

It finally makes the entry level explicable

Two reviewers said £5 read as a commodity. In a table, £10 is not a price for a template — it is CC BY turning into a commercial licence, on a line of its own, next to a free column that does not have it.

The upper two levels get named content for the first time

£500 is “a customised policy in your environment.” £1,500 is “reviews by a security expert, time with the security expert, more customisation.” Those are the first concrete descriptions either level has had, and they line up with the reviewer work from the earlier memo.

And it wants to be a PDF

“This would also make really good brochures and PDFs.” The store already generates PDFs of the walkthrough pages from the built HTML, so a table that renders well on paper is a build target rather than a second artefact.

What this does not decide

<b>Most of the cells are proposals, not facts</b>

The memo says so itself — “let’s think about this, what kind of support we can provide”, “you only get a vault in the 50 quid version” offered as an example. This store fails its own release when a page states an unproven thing as a fact. So every cell carries a state the way every claim does, and a table where half the cells read specified, never run is either the most honest pricing page on the internet or unsellable. That is a judgement, and it is not the builder’s.

Does the £10 level really not include a vault?

Offered as an example rather than a ruling, and it contradicts what the level page says today. It needs deciding before the table is published, because the table is the place the contradiction becomes visible.

What support actually means, and who answers

Email support on the paid levels is floated, not decided. It is also the second promise on this site with nobody’s name on the mailbox — the 24-hour follow-up is the first, and it has been open since it was written.
