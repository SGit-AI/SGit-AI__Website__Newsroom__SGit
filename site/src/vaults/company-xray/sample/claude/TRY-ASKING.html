Questions to start with

On the findings

  1. Walk me through F02: which months, which lines, and what would have to be true for the fall to be something other than labour?
  2. Draft the price review for October. One row per cleaning customer: current indexation, notice needed, a proposed rise, and who should call them.
  3. What would F05 look like if Calder gave notice on 30 September? Show the effect on monthly net profit.
  4. Is there any evidence in the documents that the Manchester complaints started before the supervisor left?

On the board

  1. Turn the board pack into a fifteen-minute talk for the Chair, with the three decisions we need.
  2. Write the open-actions list for the 15 October meeting from all three sets of minutes, with the age of each action.

On things the X-ray did not cover

  1. Which of the questions in questions-for-you.md could the documents we already have answer, at least partly?
  2. What would you need to see to say anything about cash?

On what to do next

  1. Draft a one-page AI use rule for a company this size, using the handbook's existing sections as the style.
  2. Write the brief for a Manchester area supervisor, using the complaints log to say what the first ninety days must fix.
  3. Which three suppliers should we renegotiate first, and why?
  4. What should the Re-X-ray in December check, to show whether any of this worked?
