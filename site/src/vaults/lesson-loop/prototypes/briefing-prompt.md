# The briefing prompt

Given every entry in a player's record since a coach last saw them, write a briefing that coach can read in two minutes before the lesson:

- how many lessons, with whom, and how many matches since;
- the player's strengths;
- what was fixed in lessons and is now holding in matches;
- what is still being worked on, and by whom;
- anything new from matches the coach has not seen;
- disagreements or different views between coaches, attributed;
- a suggested focus for this lesson.

No more than 150 words. Name coaches; never invent an observation.
