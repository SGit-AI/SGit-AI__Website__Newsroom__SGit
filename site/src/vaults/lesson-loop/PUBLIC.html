PUBLIC.md

Every byte in this vault is already public. It is published with a read key on sgit.ai, and written so that somebody who is not us can take it and build the business it describes.

  1. Nothing private committed. The player, coaches and clubs are invented. No real lessons, recordings, clips, credentials, keys or tokens.
  2. No write token. The read key that opens this vault grants read and only read.
  3. No metered capability. app.json requests "permissions": {}. The app calls no model, writes nothing and opens no network connection.

Take it, run it, change it. If you build it, the most useful thing to send back is whether coaches kept recording after the first month.
