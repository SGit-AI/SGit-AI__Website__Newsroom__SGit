# Prototypes

Enough to run the first customer. Three documents:

| File | What it is |
|---|---|
| [webmaster-playbook.md](webmaster-playbook.md) | The operating instructions the agent carries for one customer's site. Copy it into the customer's repository as `PLAYBOOK.md` and fill in the blanks. |
| [github-pages-setup.md](github-pages-setup.md) | The repository, branches, deploy and domain, step by step, as the operator's session does it. |
| [change-requests.md](change-requests.md) | Six worked change requests, from the customer's words to the commit, showing which go straight to live and which go to preview. |

None of this is code the customer has to run. It is what the agent reads and what the operator checks.
