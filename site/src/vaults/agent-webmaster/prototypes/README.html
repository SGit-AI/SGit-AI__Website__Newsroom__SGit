Prototypes

Enough to run the first customer. Three documents:

FileWhat it is
webmaster-playbook.mdThe operating instructions the agent carries for one customer's site. Copy it into the customer's repository as PLAYBOOK.md and fill in the blanks.
github-pages-setup.mdThe repository, branches, deploy and domain, step by step, as the operator's session does it.
change-requests.mdSix worked change requests, from the customer's words to the commit, showing which go straight to live and which go to preview.

None of this is code the customer has to run. It is what the agent reads and what the operator checks.
