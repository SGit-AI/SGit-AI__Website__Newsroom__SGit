# Every Cartographer page carries a map, graph or infographic; tooling to make that cheap

Add to the Cartographer's mandate: no page without a visual. Build `tools/diagrams.py`: helpers that turn
data (network.json, concepts, a list of events, a value chain in JSON) into Mermaid text, so a map is a few
lines of data, not hand-written syntax.
