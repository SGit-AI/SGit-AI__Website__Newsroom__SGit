# Epic: the back office runs on issues, with provenance

Every task and idea is an issue file in issues/ (issues-fs-lite: open, blocked, done), each citing where
it came from; the admin section renders them as a kanban and as pages; issue changes are committed with
the work that caused them. The newsroom also reports on its own changes.
