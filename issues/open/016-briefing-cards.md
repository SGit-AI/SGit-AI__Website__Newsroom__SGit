# Standing briefing cards in the same place on every piece

A card block at the top of a piece, always in the same place: what happened, where, who is waiting, what
to do next, with the sources. Filled from front matter (`cards:`) so the desks write it as data.

Done when: AUTHORING.md defines `cards`, the build renders them, the Editor's prompt asks for them.
