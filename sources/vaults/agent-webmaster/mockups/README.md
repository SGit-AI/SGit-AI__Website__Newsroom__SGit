# Mock-ups

Four standalone pages, each a single HTML file with its styles inlined and no external assets, so they open anywhere, including from this vault. The businesses are invented.

| File | What it shows |
|---|---|
| [customer-bakery.html](customer-bakery.html) | A neighbourhood bakery. Hours, the week's bread, a notice, a gallery. The kind of site that changes every Friday. |
| [customer-accountants.html](customer-accountants.html) | A two-partner accountancy firm. Services, the team, deadlines, a contact form placeholder. Credibility, kept current. |
| [customer-physio.html](customer-physio.html) | A physiotherapy clinic. Treatments, the team, a booking embed placeholder, prices. |
| [sales-site.html](sales-site.html) | The operator's own site: what the service is, the three mock-ups as examples, the prices published, and how to start. |

Each customer mock-up carries a **"changed by the webmaster"** strip near the top, showing the last three changes and when they went live. That strip is the product: a website that visibly gets updated.

To turn a mock-up into a real customer site, follow [the setup](../prototypes/github-pages-setup.md).
