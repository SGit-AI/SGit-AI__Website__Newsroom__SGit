# 8. Beyond padel

The loop works wherever one person teaches another in sessions, and knows the most about the student at the end of each one.

| Domain | The moment to capture | What the student adds between sessions |
|---|---|---|
| Tennis, squash, pickleball | The end of the lesson | Match notes and clips |
| Golf | The end of the lesson, on the range | Rounds played, scorecards, swing clips |
| Music lessons | The end of the lesson | Practice logs and recordings |
| Language tutoring | The end of the session | Real conversations, words that failed them |
| Personal training, physiotherapy | The end of the session | Workouts done, pain and progress |
| Driving instruction | The end of the lesson | Practice drives with a family member |
| Climbing, swimming | The end of the session | Routes or sessions done alone |

The pieces do not change: a voice memo, an agent, a record the student holds, a briefing for the next session. Each domain needs its own note template and its own themes.
